# Operations Insight Copilot · 运营策略分析助手

模拟互联网公司策略运营团队日常工作场景的 AI 数据分析工具 Demo：通过数据看板、指标监控、异常诊断与 AI 报告生成能力，辅助运营人员快速发现业务问题、完成业务复盘并输出优化策略。

> 纯 HTML / CSS / JavaScript 实现，零外部依赖（图表为手写 SVG 渲染），离线双击 `index.html` 即可运行。

## 功能模块

| 模块 | 说明 |
| --- | --- |
| 数据上传与管理 | CSV 上传（点击 / 拖拽）、自动解析与字段映射（中英文表头兼容）、基础数据明细表（分页 + 城市筛选） |
| 核心指标 Dashboard | 8 张 KPI 指标卡（含环比涨跌标识）+ GMV / 订单 / 用户 / 转化率趋势图 + 成本利润对比柱状图，支持按城市筛选 |
| 业务指标拆解 | 基于 `GMV = 活跃用户 × 转化率 × 客单价`，采用 LMDI 对数分解量化三因子贡献（严格加总等于 GMV 总变化），自动输出归因结论与分城市明细 |
| 异常监控与诊断 | 城市 × 指标全量扫描，环比下降超 10% 标记异常（≥20% 为严重），输出影响范围、可能原因与优化建议（结合同城市其他指标联动判断） |
| AI 复盘报告 | 一键生成结构化运营周报（业务概况 / 关键变化 / 问题诊断 / 原因分析 / 优化策略），基于真实计算结果生成，支持一键复制 |
| AI Workflow | 传统人工流程 vs AI 自动化流程对比，量化提效价值 |

## 运行方式

```bash
# 方式一：直接用浏览器打开 index.html

# 方式二：本地服务器（推荐）
python3 serve.py        # 访问 http://localhost:8765
```

打开后默认加载内置演示数据（6 个城市 × 28 天），数据中预埋了业务剧情：

- **杭州**：最近一周转化率大幅下滑 → GMV / 订单严重异常（演示转化链路问题诊断）
- **成都**：最近一周补贴成本飙升 → 利润严重异常（演示补贴效率问题诊断）
- **深圳**：持续增长（正向标杆，演示经验复制策略）

## 数据格式

CSV 表头（中英文均可）：`日期, 城市, GMV, 订单量, 活跃用户, 新增用户, 用户转化率, 平均客单价, 营销补贴成本, 利润`

- 转化率支持 `3.2%`、`3.2`、`0.032` 三种写法
- 建议数据覆盖 ≥ 14 天，以便进行周期环比与异常检测
- 示例文件：`data/sample_data.csv`（也可在「数据上传」页一键下载完整示例）

## 核心分析口径

- **周期环比**：最近 7 天 vs 之前 7 天（数据不足 14 天时对半切分）
- **聚合口径**：转化率 = Σ订单 / Σ活跃用户，客单价 = ΣGMV / Σ订单（加权而非简单平均）
- **GMV 归因**：LMDI 对数平均迪氏分解，避免「各因子变化率简单相加 ≠ 总变化」的误差
- **异常阈值**：核心指标（GMV / 订单 / 活跃用户 / 转化率 / 利润）环比下降 > 10%
